# 📺 YouTube AI 标题翻译 (Chrome 插件)
Chrome 浏览器插件：基于 DeepSeek / OpenAI 大模型，自动将 YouTube 视频标题翻译为地道中文。支持本地 Key，安全开源。

## 📖 简介
这是一个开源的 Chrome 浏览器插件，利用 AI 大模型自动将 YouTube 视频标题翻译成通顺、地道的中文。
不同于生硬的传统机翻，它能理解俚语、梗和专业术语，让你不错过任何一个优质视频。

**核心理念：** 用户自带 Key (BYOK) · 隐私安全 · 永久开源

## ✨ 核心功能

* **🦄 多模型支持：** 完美集成 **DeepSeek (V3/R1)**、**OpenAI (GPT-4o)**、**Google Gemini**。
* **⚡️ 极速翻译：** 智能缓存机制，看过的视频不再重复消耗 Token。
* **🔒 隐私优先：** 所有 API Key 仅存储在用户浏览器的本地 Storage 中，**绝不上传服务器**。
* **🛡️ 智能避险：** 内置敏感词过滤，确保使用 DeepSeek 时不会因触发布控而报错。
* **🎨 沉浸体验：** 完美融入 YouTube 原生界面，支持明亮/深色模式。

### 方法二：加载开发者模式 
1.  下载本项目代码 (Code -> Download ZIP)。
2.  解压文件。
3.  打开 Chrome 浏览器，输入 `chrome://extensions/`。
4.  打开右上角的“开发者模式”。
5.  点击“加载已解压的扩展程序”，选择解压后的文件夹。

## ⚙️ 如何配置

1.  安装插件后，点击浏览器右上角的插件图标 🧩。
2.  选择你喜欢的 AI 模型（推荐 **DeepSeek**，性价比最高，中文理解能力最强）。
3.  粘贴你的 API Key。
4.  点击“保存配置”，刷新 YouTube 页面即可见证魔法！
