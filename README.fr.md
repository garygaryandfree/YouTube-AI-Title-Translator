AI Title Translator est une extension Chrome qui traduit les titres YouTube avec l’IA. Le titre traduit apparaît en premier et le titre original reste dessous pour comparer et apprendre.

Depuis V8, l’extension peut traduire vers l’anglais, le japonais, le coréen, le thaï, l’espagnol, le français, l’allemand, le portugais, l’indonésien, le vietnamien et le chinois.

## Fonctions clés

| Reconnaissance multilingue | Traite automatiquement des titres dans de nombreuses langues prises en charge |
|---|---|
| Traduction contextuelle IA | Comprend les accroches, l’argot, les abréviations et le contexte local |
| Traduction + original | Traduction au-dessus, original en dessous |

## Interface de configuration

![Extension settings UI](screenshots/v8/config-ui.png)

`Interface language` change uniquement la langue de la page de configuration. `Translate titles into` chooses the target language for YouTube titles. Turn on `Translation`, choose an AI provider and model, paste your API Key, save, then refresh YouTube.

## Supported languages

**Target languages:** Simplified Chinese / Traditional Chinese / English / Japanese / Korean / Thai / Spanish / French / German / Portuguese / Indonesian / Vietnamese

**Interface languages:** English / 简体中文 / 日本語 / 한국어 / ไทย / Español / Français / Deutsch / Português / Bahasa Indonesia / Tiếng Việt / Русский / العربية / हिन्दी

## Démarrage rapide

Installez depuis le Chrome Web Store ou téléchargez le dernier `YouTube_AI_Title_Translator_v8.0.zip` depuis GitHub Releases, puis chargez-le dans `chrome://extensions/` en mode développeur.

## API providers

OpenAI, Google Gemini, Claude, DeepSeek, MiniMax, Z.AI, Kimi, and custom OpenAI-compatible endpoints are supported. Gemini presets include `gemini-3.5-flash`, `gemini-3-pro-preview`, `gemini-3-flash-preview`, and `gemini-2.5-flash`.

## Privacy

API keys, target language, interface language, and provider settings are stored only in Chrome local storage. Title text is sent only to the AI provider configured by the user.
